Presentation tools

Every command and helper of CustomPresentations in one place. Commands run from this repository (D:\Code\CustomPresentations) and work on any presentation folder; a presentation folder itself never needs the repository. Details: AUTHORING.md (how to write slides) and SPEC.md (design decisions).

Typical workflow

new.py creates the folder
Edit the deck (open it with ?dev)
image_sizes.py after adding images
check.py after every change
pack.py makes the zip to submit

Old presentation and a newer template? update.py brings it to the newest engine first.

Command-line tools

tools/new.py start a presentation

Creates a self-contained presentation folder. Asks for folder, file prefix, title, subtitle, presenter, course title/type, semester and — one prompt per animation, empty answer = done — animation names. Empty answers keep the template placeholders.

python tools/new.py "D:\Talks\MyTalk"

Creates MyTalk_presentation.html, one <name>_animations.html per animation (already registered in DECK.animations), images/eth_zurich_aerial.png, and the AI helpers CLAUDE.md + AUTHORING.md. Answers can be piped in, one per line.

tools/check.py after every change

Opens the deck headless in Chrome/Edge (offline) and lists everything the ?dev view would show, per slide and step: missing images/animations, invalid step attributes, formula errors, files outside the folder, … Also reports <img> tags with missing/wrong width/height and outdated engine versions.

python tools/check.py "D:\Talks\MyTalk"          # folder or deck file
python tools/check.py "D:\Talks\MyTalk" --json   # machine-readable

Exit code 0 = nothing to fix, 1 = problems, 2 = wrong arguments.

tools/image_sizes.py after adding or changing images

Writes each image's natural pixel size into its <img> tag, so a missing image still keeps its place and shape. Writes a .bak backup.

python tools/image_sizes.py "D:\Talks\MyTalk\MyTalk_presentation.html"
python tools/image_sizes.py "…_presentation.html" --check   # report only, exit 1 if wrong

tools/update.py older presentation, newer template

Replaces only the generated engine blocks (deck: DECK-ENGINE; animations: ANIM-VENDOR, ANIM-CONTRACT), verifies that nothing else changed, writes .bak backups and refreshes CLAUDE.md / AUTHORING.md. Refuses to downgrade.

python tools/update.py "D:\Talks\MyTalk"
python tools/update.py "D:\Talks\MyTalk" --dry-run   # only report
python tools/update.py "D:\Talks\MyTalk" --force     # allow a downgrade

tools/pack.py submit

Writes <prefix>.zip next to the folder (or into --out) with only the presentation files: deck, animation files, images and anything else in the folder — without CLAUDE.md, AUTHORING.md, *.bak, zips and hidden files. Before zipping, a copy is checked in a temporary folder outside the repository, so the zip is proven to work on its own and offline.

python tools/pack.py "D:\Talks\MyTalk"
python tools/pack.py "D:\Talks\MyTalk" --out "D:\Submissions"
python tools/pack.py "D:\Talks\MyTalk" --force   # zip even with problems

Repository development

tools/build.py after changing engine/

Generates template/, examples/*/…_presentation.html and AUTHORING.md from the engine sources. --check exits 1 if anything generated is stale.

python tools/build.py
python tools/build.py --check

tools/fetch_vendor.py changing a font or KaTeX version

Downloads the pinned fonts and KaTeX listed in engine/vendor/manifest.json and writes the hash lock; --verify checks the vendored files offline.

python tools/fetch_vendor.py
python tools/fetch_vendor.py --verify

Tests after every engine or tool change

Build and engine tests; the engine tests run fixture decks in headless Chrome/Edge (skipped without a browser).

python -m unittest discover tools/tests
